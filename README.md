### 🧑‍💻 About me

- 🔭 Software engineer at **[NTG Clarity](https://ntgclarity.com)**, building **[Markatty](https://markatty.com)**: a multi-tenant e-commerce SaaS with **70+ live storefronts** and **10,000+ monthly users**.
- 👥 I lead a team of 3 developers.
- 🧱 Designed the storefront layout system behind **101+ themes**, and built the Next.js Super Admin that replaced the legacy one: **100+ pages**, role-based access, RTL.
- 🧪 Set up storefront testing with Vitest, Playwright and Storybook: **2,900+ tests**.
- 🤖 I utilize AI-powered workflows with Claude Code and Cursor, with project rules and custom agent skills.
- 🌱 Currently building an issue tracker with an MCP server, so AI agents can create, move and summarise issues.
- 💬 Ask me about the Next.js App Router, multi-tenant theming, RTL / Arabic UI, and frontend testing.
- 📊 Fun fact: I started out as a data analyst, so I measure before I optimise.
- 🌍 Cairo, Egypt (UTC+2/+3). Open to remote roles with EU and US overlap hours.
- 🗣️ Arabic (native) · English (B2) · German (B1)
